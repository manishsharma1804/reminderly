# 🚀 How to Install Reminderly in Chrome

Follow these quick steps to load **Reminderly** into Google Chrome Developer Mode:

### Step 1: Open Chrome Extensions Page
1. Launch **Google Chrome**.
2. Type `chrome://extensions` into your address bar and press **Enter**.

---

### Step 2: Enable Developer Mode
1. In the top right corner of the Extensions page, locate the **Developer mode** toggle switch.
2. Turn the **Developer mode** toggle **ON**.

---

### Step 3: Load the Unpacked Extension
1. Click the **Load unpacked** button that appears in the top left action bar.
2. In the file picker dialog, navigate to the project directory:
   `/Users/anish/Documents/reminderly`
3. Click **Select** (or **Open**).

---

### Step 4: Pin Reminderly for Easy Access
1. Click the puzzle icon (🧩) next to your Chrome address bar.
2. Locate **Reminderly – AI Smart Reminder Assistant**.
3. Click the **Pin** icon to pin Reminderly to your toolbar.

---

### Step 5: Test Extension Features
- **Popup UI**: Click the Reminderly toolbar icon to check quick stats, log water intake, or start a Focus Mode session.
- **Full Dashboard**: Click the gear icon (⚙️) in the popup or right-click the extension icon and choose **Options**.
- **Floating Remi Mascot**: Trigger a reminder or test Remi's animations in the **Remi Mascot Studio** tab.
- **Distracting Site Blocker**: Navigate to `reddit.com` or `youtube.com` during Focus Mode to experience the glassmorphic blocker overlay.
